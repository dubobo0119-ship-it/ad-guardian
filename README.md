# 广告卫士（AdGuardian）

> 遇到流氓广告别忍着——**拍张截图，30 秒生成一份引用法规条款的举报文书，照着指引提交给官方渠道。**

一个面向普通用户（尤其是帮长辈清理手机的家庭场景）的**违规广告取证举报助手**：
自动识别违规广告类型 → 匹配法规依据 → 生成结构化举报文书 → 指引官方举报渠道 → 跟踪处理时限。

## 为什么做这个

开屏摇一摇乱跳、关不掉的弹窗、"恭喜获得 100 元红包"式诱骗广告……这些都有明文法规禁止，
但绝大多数人**不知道能举报、不知道找谁、不会写举报材料**。

屏蔽广告的工具（如李跳跳）因《反不正当竞争法》第十二条被叫停，
而**帮助用户向官方渠道依法举报，方向恰好相反——站在监管这一边**。这是本项目存在的合规基础。

## 核心功能

| 功能 | 说明 |
|---|---|
| 🔍 智能识别 | 一句话描述 → 规则引擎推断违规类型（命中关键词可解释，零成本可离线） |
| 🤖 AI 看图 | 上传截图，免费多模态模型（智谱 GLM-4V-Flash）陈述界面事实，规则代码判定违规（AI 只陈述、判定可复现） |
| 📜 文书生成 | 六段式举报文书：举报对象/违规事实/涉嫌违反的规定/证据材料/诉求/建议渠道，自动引用法规条款 |
| 🧭 渠道匹配 | 8 类违规 × 4 个官方渠道（12321 / 12315 / 12377 / 工信部）按标签自动匹配，附分步提交指引与直达入口 |
| 📅 举报记录 | 本地记录提交时间，按工作日计时，满 15 个工作日提醒查询处理结果 |
| 📚 知识库 | 违规类型、法规依据、取证要点、渠道信息的完整科普页 |

## 违规知识库（8 类）

摇一摇误触跳转 · 无关闭按钮 · 虚假关闭按钮 · 套娃连环弹窗 · 虚假倒计时 ·
诱导欺骗点击 · 强制跳转/静默下载 · 虚假夸大广告

依据：《广告法》《互联网广告管理办法》《互联网弹窗信息推送服务管理规定》及工信部专项整治要求。

## 项目结构

```
ad-guardian/
├── adguardian/           # 核心包
│   ├── rules.py          #   违规知识库(8 类违规 + 4 渠道 + 标签匹配)
│   ├── auto.py           #   规则引擎识别 / EXIF 时间提取 / App 联想
│   ├── vision.py         #   智谱视觉模型:AI 陈述事实 + 规则判定
│   └── report.py         #   举报文书生成器 + 渠道匹配
├── api.py                # FastAPI 接口层(供小程序调用)
├── app.py                # Streamlit 网页版(三页应用)
├── wxapp/                # 微信小程序前端
│   ├── pages/index       #   一键举报(识别→确认→文书→渠道→记录)
│   ├── pages/kb          #   违规知识库
│   ├── pages/records     #   举报记录(工作日计时提醒)
│   └── pages/feedback    #   意见反馈
├── Dockerfile            # 微信云托管部署镜像
└── 部署手册_云托管上线.md  # 小程序上线全流程手册
```

## 快速开始

```bash
pip install -r requirements.txt

# 网页版(8502)
python -m streamlit run app.py --server.port 8502

# 接口服务(8000,供小程序/前端调用)
$env:ADGUARDIAN_ZHIPU_KEY='你的智谱密钥'   # 可选:启用 AI 看图
python api.py
```

小程序端：用微信开发者工具导入 `wxapp/` 目录（开发阶段接口指向本机 8000）。

## 部署

推荐微信云托管（免域名免备案）：见 `Dockerfile` 与《部署手册_云托管上线.md》。
密钥等敏感配置一律通过环境变量注入，不入库。

## 合规声明（必读）

- 本项目是**辅助工具**：帮助用户整理解读法规知识、生成供本人使用的举报材料；
- **不提供、也不支持"代举报/代投诉"**：举报必须由用户本人实名向官方渠道提交；
- 文书措辞刻意采用"涉嫌"等客观表述，引导如实陈述，反对滥用举报机制；
- 知识库内容依据公开发布的法规与整治要求整理，仅供普法参考，不构成法律意见；
- 本项目不从事任何形式的广告屏蔽、破解或流量劫持行为。
